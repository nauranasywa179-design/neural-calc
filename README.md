# NEURAL // CALC — Scientific Calculator

## Deskripsi Program
NEURAL // CALC adalah aplikasi kalkulator ilmiah sederhana berbasis web yang dibuat menggunakan HTML, CSS, dan JavaScript. Program ini memiliki tampilan bertema teknologi dan coding dengan desain cyberpunk yang terinspirasi dari antarmuka developer.

## Fitur
- Operasi matematika dasar seperti penjumlahan, pengurangan, perkalian, dan pembagian.
- Perhitungan ilmiah berupa sinus, cosinus, tangen, akar kuadrat, pangkat dua, dan persentase.
- Konversi mode sudut DEG dan RAD.
- Fitur hapus karakter dan reset perhitungan.
- Dukungan input melalui keyboard.
- Tampilan terminal dan source code sebagai elemen visual bertema IT.

## Teknologi yang Digunakan
- **HTML** — menyusun struktur halaman dan tombol kalkulator.
- **CSS** — mengatur tampilan, warna, animasi, dan desain responsif.
- **JavaScript** — mengatur interaksi tombol dan proses perhitungan.

## Struktur File
- `index.html` — struktur utama aplikasi.
- `style.css` — desain dan tampilan aplikasi.
- `script.js` — logika kalkulator dan fungsi perhitungan.

## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Pastikan ketiga file berada dalam folder yang sama.
3. Buka file `index.html` menggunakan browser.
4. Gunakan tombol kalkulator untuk melakukan perhitungan.

## Tujuan
Program ini dibuat untuk menerapkan penggunaan HTML, CSS, dan JavaScript dalam pengembangan aplikasi web interaktif serta memahami penerapan fungsi dan event handling pada JavaScript.
